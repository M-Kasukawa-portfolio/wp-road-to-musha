# 武者への道（WordPressテーマ）

Hello Mentor 課題で制作した、架空メディアのWordPressテーマです。
Figmaのデザインカンプに基づきコーディングした静的サイトを、WordPress化しました。

## Demo

https://wptask01.mkdesignworks.net/

## 概要

- 内容: トップ／下層／ブログ（投稿）／お問い合わせなど
- 位置づけ: 学習課題（実務案件ではありません）
- 担当: コーディング〜WordPress化（デザイン・レイアウト設計は含みません）
- 方針: カンプ準拠。レスポンシブはオーソドックスな実装

## 使用技術

HTML5 / Sass(SCSS) / JavaScript / WordPress

## この課題で扱ったこと

カンプ通りの静的実装を前提に、投稿・固定ページ・共通パーツを
WordPressのテンプレート構成へ落とし込む流れを学びました。
あわせて、管理画面からの更新やフォーム連携など、
公開後の運用を意識したCMS寄りの実装にも触れました。
